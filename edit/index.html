開始前，你可能想問

要付費嗎？

技能免費。付費方案用「加入外掛」安裝並自動更新；免費版用 zip 安裝也可以用；剪輯需要跑程式，影片越長、越多次修改，用到的額度越多，可用量以你的 Claude 方案為準。

找不到 heiniu-video-editor？

到 外掛頁 確認 heiniu-video-editor 是開的，然後在對話第一句直接說「用黑牛 AI 剪輯幫我剪這支影片」。如果加 marketplace 時被拒絕，多半是公司帳號限制了來源，請管理員允許，或改用 zip 安裝。

出現「Zip must contain a .claude-plugin/plugin.json」？

你把技能檔上傳到外掛的地方了。付費版最簡單：外掛頁 → Add → Add marketplace → 貼上 FATTY-BAMBA/heiniu-tools，不用下載任何檔案。要用上傳的話，請改下載 外掛檔。免費版請到技能頁上傳 heiniu-video-editor.zip。

上傳 zip 時失敗了？

最常見的三個原因：① 上傳的是解壓後的資料夾，不是 .zip；② 沒有先打開 Settings → Capabilities 裡的 Cloud code execution and file creation；③ 自己改過 zip 裡的資料夾名稱。重新下載原本的 zip 再上傳一次就好。

裝好了，但 Claude 好像沒有用到技能？

先到 Customize → Skills 確認開關是開的，然後在對話第一句直接說「用黑牛 AI 剪輯幫我剪這支影片」。Claude 開始給你分鏡頁，就代表技能在運作。

我的素材是 4K、檔案很大，上傳不了怎麼辦？

先在手機或電腦把素材輸出成 1080p 再上傳就好，成品本來就是 1080×1920。如果你用 Claude 桌面版並連結了電腦資料夾，也可以直接讓 Claude 讀那個資料夾。

我的影片會被傳到黑牛這邊嗎？

不會。技能是一包說明和程式，在你自己的 Claude 對話裡執行，素材和成品都只在你的對話裡。

只能剪中文嗎？

中文（會轉成台灣繁體）、英文、粵語、日文、韓文都可以轉字幕。第一次使用時會自動下載語音辨識模型，如果你的環境不能下載，Claude 會請你提供一份字幕檔（.srt，剪映或手機自動字幕都能匯出）。

貼一次，就會跟黑牛的影片一模一樣嗎？

不會一模一樣。素材、講稿和你每次的修改都會影響結果。先確認分鏡、再用一句話慢慢調，通常兩三輪就會很像你要的樣子。影片裡的「台北 101 頂樓換景」是另外用 AI 影片工具做的，這個技能不包含。

加音樂呢？

建議發 IG / TikTok 時直接在 App 裡選熱門音樂，音量調到 10–15%。也可以給 Claude 一首可商用的音樂檔，它會自動在你講話時把音樂壓低。
