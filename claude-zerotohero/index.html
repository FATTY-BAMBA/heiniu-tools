CHAPTER 00

為什麼 99% 的人都用錯

把 Claude 當 Google 用，你只用到它 10% 的能力。

大多數人的用法是：開一個新對話 → 丟一句問題 → 拿到一段文字 → 自己複製到 Word 或 LINE。每次都從零開始，每次都要重新解釋自己是誰。

高手的用法完全不同：Claude 記得你是誰、每件工作有自己的專案、它可以直接讀你的信箱和雲端硬碟、它直接交出 Word 檔和簡報，最後它會在你睡覺的時候自己把事情做完。

一般人「幫我寫一封道歉信」
→ 拿到一封通用、沒溫度的信，再自己改半小時。
高手在「客服」專案裡說「回這封客訴」
→ Claude 已經知道你的店、語氣和退款規則，直接給可以寄的版本。
一般人「幫我排台南兩天一夜」
→ 拿到網路上到處都有的景點清單。
高手在「家庭出遊」專案裡說「排這週末台南」
→ Claude 已經知道你帶兩個小孩、不吃辣、預算一萬，直接排好、附交通時間。

三個模型，怎麼選

Haiku最快。分類、翻譯、整理格式這種簡單又大量的事。
Sonnet日常主力。寫信、整理、分析，90% 的工作用它就夠。

常見錯誤

  • 同一個對話聊到超長，每次回覆都在重讀前面全部內容，額度掉超快 → 換題就開新對話（省 token 三招）。
CHAPTER 02

記憶：讓 Claude 記得你

講一次你是誰，之後每個對話都不用再講。

開啟記憶之後，Claude 會記住你的工作、你的專案、你喜歡的回答方式。它的記憶以工作相關的內容為主，你可以隨時到 設定 → 記憶 看它記了什麼、刪掉不想要的。

從 ChatGPT 搬家（5 分鐘）

  1. 到 ChatGPT 貼上下面這段指令，讓它把記得你的事全部列出來。貼過去之前，先刪掉你不想帶走的敏感資料。
  2. 回到 Claude，打開 設定 → 記憶，按 Start import（開始匯入）。
  3. 把 ChatGPT 給你的內容貼進去，按 Add to memory。
  4. 問 Claude：「我更新了記憶，你學到了什麼？」檢查它有沒有記對。
貼到 ChatGPT
請把你記得關於我的所有記憶和背景資訊，完整列在一個程式碼區塊裡。包括：我的工作和職稱、正在進行的專案、我常用的工具、我喜歡的回答方式和語氣、還有任何你在對話中學到關於我的事。用條列式，每一點一行。

沒用過 ChatGPT？直接自我介紹

貼到 Claude
請記住以下關於我的事：
我是 [職業／職稱]，在 [公司或產業] 工作。
我最常請你幫忙的事是 [例如：回客戶信、做報價單、寫 IG 文案]。
回答我的時候：用台灣繁體中文、直接講重點、[其他偏好，例如：先給結論再解釋]。

常見錯誤

  • 把身分證字號、帳號密碼這種資料丟進記憶。
  • 以為它什麼都會記，其實它以工作內容為主，生活瑣事可能不會留。
  • 從來不去 設定 → 記憶 檢查，舊的、錯的資訊一直影響回答。
CHAPTER 03

下指令：背景、任務、格式

AI 回答爛，九成是因為你沒給背景。三段式就能解決。

不用背什麼神奇咒語。把 Claude 當成一個很聰明但第一天上班的新同事：他不知道你的客戶是誰、不知道老闆喜歡什麼格式。你跟新同事交代事情要講什麼，就跟 Claude 講什麼。

太模糊「幫我寫一封信給客戶說延遲出貨。」
三段式背景：我開網路服飾店，這位是三年的老客人。
任務：寫信告知她訂的外套延遲 5 天，補償免運券。
格式：LINE 訊息，150 字內，親切不卑微。
太模糊「幫我回阿姨的訊息。」
三段式背景：阿姨在家族群組傳長輩圖，順便問我什麼時候結婚。
任務：回一句有禮貌、但不正面回答的話。
格式：LINE 訊息，20 字內，輕鬆，一個表情符號。

萬用模板

三段式指令
背景：[你是誰、這件事的來龍去脈、對象是誰]
任務：[你要它做什麼，一次一件事]
格式：[長度、語氣、要用條列還是表格、要給幾個版本]

這是我之前寫過、覺得不錯的範例，請參考它的風格：
[貼一個範例]

兩個黑牛最常用的技巧

先讓它問你

任務很複雜時，在最後加一句「開始之前，先問我 3 個你需要知道的問題」。它問的問題，常常就是你忘了講的背景。

給範例勝過形容

「語氣要專業但親切」很模糊。貼一封你之前寫過的信，說「照這個語氣」，效果好十倍。

常見錯誤

  • 一次塞十件事，結果每件都做一半。
  • 只說「幫我優化一下」，它不知道你要更短、更正式還是更好笑。
  • 不滿意就整個重問。直接說「第二段太硬，改口語一點」，比重來快很多。
CHAPTER 04

專案：一件工作，一個大腦

把常做的工作做成專案，背景資料和規則只要設定一次。

專案就是一個資料夾，裡面放這件工作專用的檔案和專案指令（Claude 在這個專案裡永遠要遵守的規則）。在專案裡開的每個對話，Claude 都會自動讀這些東西。

適合做成專案的事

報價單

放價目表、過去的報價單、公司資料。之後只要說「幫 ABC 公司報 3 台機器的價」。

客服回覆

放退換貨規則、常見問題、你的回覆語氣範例。客人訊息貼進來就有回覆草稿。

IG 文案

放你過去表現最好的貼文、品牌用語、不能說的字。

找工作

放你的履歷和作品集。每次貼一個 104 職缺，讓它幫你改成對應的版本。

旅行規劃 生活

放機票、訂房確認信、想去的店。之後問「第二天下午下雨怎麼辦」，它知道你住哪、幾點要趕車。

家庭記帳 生活

放每月預算和分類規則。每個月把信用卡明細貼進來，它幫你分類、抓出超支的地方。

照做：建立第一個專案

  1. 左側選單點 專案 → 新增專案，取一個清楚的名字，例如「客服回覆」。
  2. 上傳這件工作會用到的檔案：規則、範例、價目表。
  3. 在專案指令貼上下面的模板，改成你的內容。
  4. 開一個新對話測試，不滿意就回去改專案指令，不要每次在對話裡重講。
專案指令範例：客服回覆
你是 [店名] 的客服助理。
我會貼上客人的 LINE 或 IG 訊息，請你寫回覆草稿。

規則：
1. 退換貨一律依照「退換貨規則」檔案，不要自己承諾例外。
2. 語氣：親切、像朋友，用台灣口語，可以用一個表情符號。
3. 每則回覆 100 字內。
4. 如果客人很生氣，先道歉再解決，不要解釋原因。
5. 遇到規則沒寫到的情況，不要回覆，直接告訴我「這題需要你決定」。

常見錯誤

  • 所有事情都丟在同一個專案，背景互相干擾。
  • 價目表改了，專案裡的檔案沒換，Claude 一直報舊價格。
  • 免費版最多 5 個專案，先挑最常做的 5 件事。
CHAPTER 05

連接你的工具

不用再複製貼上。讓 Claude 直接讀你的信箱、行事曆和雲端硬碟。

在 設定 → 連接工具（Connectors） 可以連上 Gmail、Google 日曆、Google 雲端硬碟、Microsoft 365、Slack 等等。連上之後，你在對話裡提到它們，Claude 就會自己去查。

連上之後可以這樣問

Gmail ＋ 日曆
看我這週的 Google 日曆，找出兩段可以專心工作 2 小時、中間沒有會議的時段。
再從 Gmail 找出過去 7 天客戶寄來、我還沒回的信，列成表格：寄件人、主旨、要我做什麼、急不急。
雲端硬碟
在我的雲端硬碟找「[檔名或關鍵字]」的最新版本，幫我整理成 5 點重點，然後列出裡面跟上個版本比起來改了什麼。
生活：日曆 ＋ Gmail
看我這個月的 Google 日曆，列出還沒排事的週末。
再從 Gmail 找出這個月要繳的帳單（電費、電信、信用卡），列成表格：項目、金額、繳費期限，照期限排序。
老實說：LINE、蝦皮、104 目前沒有可以直接連的工具。替代做法是匯出 CSV、或截圖貼進對話，Claude 一樣讀得懂。

常見錯誤

  • 一次把所有工具都連上，卻不知道它能看到什麼。只連你真的會用的。
  • 連上了但沒有在指令裡說「去我的 Gmail 找」，它就不會去找。
  • 讓它直接寄信、改行事曆之前，先確認它給的內容，再按同意。
CHAPTER 06

Skills：把你的 SOP 教給 Claude

專案是「背景資料」，Skill 是「做事的方法」。教一次，之後每次都照你的標準做。

Skill 就是一份說明書：告訴 Claude 某件事一步一步要怎麼做、做完要檢查什麼。裝好之後，你只要提到那件事，Claude 會自己拿出說明書照做。它還可以附上程式和範本，做到一般對話做不到的事。

黑牛推薦

黑牛 AI 剪輯 黑牛自製

丟原始素材 → 看分鏡 → 用一句話修改，拿到有字幕、封面和留言結尾的短影音。

免費下載＋三步安裝 →
Word／Excel／PPT／PDF 內建

報價單、報表、簡報、合約整理。直接說「做成 Excel」，它就會用這些 skill 交出真的檔案。

做你自己的 skill 內建

把你每週重複做的流程講給 Claude 聽，它會幫你寫成 skill。這是從「會用」變成「高手」的那一步。

例子：客訴處理流程

貼客人訊息 → 判斷問題類型 → 照店裡規則寫回覆 → 需要老闆決定的標出來。每天都在做、步驟固定，就適合做成 skill。

照做：把你的流程變成 skill

做一個自己的 skill
我每週都要做 [一件重複的工作，例如：把會議錄音整理成給老闆的週報]。
我的做法是：
1. [第一步]
2. [第二步]
3. [第三步]
做完之後我會檢查：[你的品質標準]

請幫我把這個流程做成一個 skill。先問我你還需要知道的事，再寫。

常見錯誤

  • 流程還沒固定就急著做 skill。先手動做 3 次，確定步驟再做。
  • 安裝來路不明的 skill。Skill 可以執行程式，只裝你信得過的來源。
CHAPTER 07

直接交成品：文件、簡報、表格、網頁

不要叫它「寫內容」再自己貼到 Word。直接要成品。

現在 Claude 在一般對話裡就能交出可以編輯的文件、有公式的試算表、可以用 PowerPoint 開的簡報，還有圖表和互動網頁。2026 年 9 月起，原本的 Cowork 功能已經合併進一般對話，不用再切換模式，Claude 會自己判斷要用哪個工具。

簡報
把附件的會議記錄做成給老闆看的 5 頁簡報：第一頁結論，中間三頁各講一個決議和負責人，最後一頁是下週待辦。要可以下載成 PowerPoint。
試算表
做一個報價單試算表：欄位是品項、數量、單價、小計，下面自動算未稅總計、5% 營業稅和含稅總計。品項先放 3 筆範例資料。
生活：旅行行程表
幫我把台南兩天一夜做成行程表：欄位是日期、時間、地點、交通方式、預估花費。最後一列自動加總花費。我們 2 大 2 小、開車、不吃辣，預算一萬。

常見錯誤

  • 要文字 → 自己貼到 Word → 自己排版。浪費最多時間的就是這一步。
  • 沒說誰要看。「給老闆看」和「給客戶看」做出來的東西完全不一樣。
CHAPTER 08

Claude Code：不會寫程式也能做工具

你說要什麼工具，它寫程式、測試、修 bug。

Claude Code 是讓 Claude 直接在你的電腦或雲端寫程式的工具，Pro 方案以上可以用。你現在在看的這個網站，包括 薪水實拿計算機，都是我用講的叫 Claude 做出來的。

從小工具開始

做一個小工具
幫我做一個單一網頁的小工具：[例如：輸入月薪，算出扣掉勞健保後實拿多少]。
要求：
- 只用一個 HTML 檔，打開瀏覽器就能用
- 手機上也要好用
- 用台灣繁體中文
做完之後，用三組數字測試計算對不對，再告訴我結果。

常見錯誤

  • 第一次就要做「一整套 ERP 系統」。先做一個只做一件事的小工具。
  • 沒有叫它測試。最後一句一定要加「做完自己測試」。
  • 它要執行指令或刪檔案時，看都不看就按同意。
CHAPTER 09

排程任務：讓 Claude 自己定時做事

LV 5：你不用開口，它每天早上就把事情做好等你。

付費方案可以設定排程任務。直接在對話裡說「每天／每週幾點幫我做什麼」，Claude 會問你幾個問題，給你確認名稱、時間和指令，按 Schedule 就好。任務在雲端執行，你的電腦關機也會照跑（需要讀你電腦裡檔案的任務除外）。

四個馬上能用的排程

每天早上 8 點
每個平日早上 8 點，幫我做一份晨報：
1. 今天 Google 日曆上的會議，每個會議前我需要準備什麼
2. Gmail 過去 24 小時客戶寄來、還沒回的信
3. 今天最該先做的 3 件事
用條列式，3 分鐘內看得完。
每週一早上
每週一早上 9 點，搜尋過去 7 天 [你的產業] 在台灣的重要新聞和競爭對手 [A、B、C] 的動態，整理成 5 點，每點附來源連結，最後告訴我哪一點可能影響我的生意。
每週五下午
每週五下午 4 點，讀我雲端硬碟「[週報資料夾]」裡這週更新的檔案，幫我寫好給主管的週報草稿：完成了什麼、卡在哪、下週計畫。
生活：每週日晚上
每週日晚上 8 點，幫我整理下週的家庭行程：
1. Google 日曆上下週的行程（小孩活動、聚餐、看醫生）
2. 下週要繳的帳單和期限
3. [你住的城市] 下週的天氣，哪幾天要帶傘
